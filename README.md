# HTML → PDF Converter

A beautiful, free, and fully offline HTML to PDF converter. Upload or paste your HTML and get a pixel-perfect PDF — no signup, no cost, no data leaves your browser.

## Features
- 📄 Drag & drop HTML file upload
- 📋 Paste HTML code directly
- ⚙️ Page size, orientation, and quality settings
- 👀 Live HTML preview
- ⬇️ One-click PDF download
- 🔒 100% client-side — nothing leaves your browser

## Deploy on Vercel

1. Push this repo to GitHub
2. Go to [vercel.com](https://vercel.com) → Import project
3. Select this repo → Deploy
4. Done! Your converter is live 🎉
